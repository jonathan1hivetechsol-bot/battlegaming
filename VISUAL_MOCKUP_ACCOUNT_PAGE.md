## Data Flow

```
Supabase Database
    ↓
cod_accounts table
    ├─ unique_description (TEXT)
    ├─ average_rating (DECIMAL)
    ├─ review_count (INTEGER)
    ├─ reviews (JSONB Array)
    └─ buying_amount (INTEGER)
    ↓
Next.js Account Page
    ├─ generateMetadata() → SEO Tags
    ├─ Price Display
    ├─ Description Section
    ├─ Reviews Section
    ├─ Stats Grid
    └─ Canonical Tags
    ↓
Browser Rendering
    ├─ Orange accents (#FF7828)
    ├─ Dark theme (#0d071a)
    ├─ Interactive hover states
    └─ Responsive layout
```

## User Interaction

### Desktop User Flow
1. User visits account page
2. Reads title and description
3. Scrolls down to see reviews
4. Checks rating (⭐⭐⭐⭐⭐)
5. Reads individual reviews
6. Looks at price in sidebar
7. Clicks "Buy Now" button
8. Completes purchase

### Mobile User Flow
1. User visits account page
2. See title and description at top
3. See price box and buttons
4. Scroll down for reviews
5. See trust signals ("85+ sold")
6. Read reviews
7. Click buy button
